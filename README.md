# 末光殖民地 Lastlight Colony — v0.4（第 1–5 章，English／繁體中文）

依 GDD v0.2 §16 的 MVP 範圍實作，並加上第 4 章（戰鬥、武器、異晶）與第 5 章（治理、貿易）：階段 1–3（16 棟建築）、點擊暴擊與工人 buff、建築升級線、資料庫研究、
食物安全度與人口成長、主線第 1–3 章、事件（隕石雨、求救訊號）、離線收益、本機存檔、數值模擬器。

## 指令

```bash
npm install
npm run dev      # 開發伺服器
npm run build    # 輸出 dist/index.html（單一檔案，含全部 JS/CSS）
npm run sim      # 數值模擬：貪婪策略玩完 MVP，列出各階段抵達時間
npm run sim -- 0.15   # 參數＝按住點擊的時間比例（預設 0.5）
```

## 結構（對應 GDD §15）

```
src/
  data/        buildings.json、research.json、story.json、events.json（數值都在這裡調）
  engine/      純邏輯，不碰畫面：state、formulas、production、population、click、events、story、actions、tick、offline
  store/       gameStore.ts：Zustand store、200ms 時間累加器、自動存檔
  scene/       GameScene.ts（Pixi）：地圖、建築／工地、工人、點擊回饋；layout.ts 固定建築位置
  ui/          React：資源列、主線任務、殖民地狀態、建築面板（工人／升級線／研究）、快捷列、對話框、設定頁
  i18n/        語言切換：strings.ts（介面文字 [英, 中]）、data-en.ts（建築／研究／憲章／章節／事件的英文）
  art/art.js   程序化像素美術模組
sim/balance.ts 無畫面模擬器
```

## 語言與設定

- 預設英文，右上角 ≡ 開啟設定頁可切換繁體中文；選擇存在 localStorage `lastlight-colony-settings`。
- 引擎不產生顯示文字：通知、不能操作的原因、戰報與事件結果都存成 `{ k, p }`（代碼＋參數），由 `i18n.tm()` 依目前語言翻譯，所以切換語言後舊通知也會跟著換。
- 中文資料文字仍放在 `data/*.json`，英文放在 `i18n/data-en.ts`；新增建築或研究時兩邊都要補。
- 主線目標的完成紀錄從中文文字改成 id（`章-序號`），讀取舊存檔時自動轉換。
- 設定頁另有：存檔資訊、立即存檔、刪除存檔重來、關於。

## 科技樹

- 研究獨立成一頁「科技樹」（右上角「科技」按鈕，或科技研究院／異星研究院面板的「開啟科技樹」）。
- 三條分支：生產、民生、軍事；每項科技可有多個前置科技（`research.json` 的 `requires` 陣列）、解鎖階段（`stage`）、是否需要異星研究院（`lab`）。
- 研究速度全殖民地共用＝科技研究院＋異星研究院的研究員人數；兩棟建築的頁面只保留派人、升級與目前研究進度。
- 資料庫改名為科技研究院（英文 Tech Institute）。

## 第 4 章

- 新建築：水耕農場、紀念堂、異晶合成室、陸戰隊營區、水循環站，指揮艙 Lv4 殖民地核心（需要人口 40、擊退 2 次襲擊）
- 新資源：武器（鍛造廠可分配工人改做武器）、異晶（異晶合成室；金屬礦井「晶脈感應」點擊掉落）
- 戰鬥（`engine/combat.ts`）：預警 60 秒 → 最多 10 回合自動結算 → 戰報。陸戰隊員不會死，倒下的受傷休養 3 分鐘
- 新研究：異晶護甲、應急口糧、異晶共振

## 第 5 章

- 新資源：信用點（稅收、交易站、賣資源；不受倉容上限限制）
- 行政中心：稅率 0–4 級（人口 × 0.02 × 等級，每級士氣 −5）、殖民憲章 6 條（初始 1 欄，升級線「議會擴編」+1）
- 貿易（`engine/governance.ts`）：赫利昂企業（交易站，匯率最好）、自由殖民地聯盟（太空港，完成委託提高聲望與匯率）、神秘訊號（太空港＋異星研究院，40 廢料換 1 異晶，每 10 分鐘限 30 個）
- 企業使者：每 7 分鐘要求上繳；拒絕 3 次以上，之後的襲擊會輪流改成企業突擊隊（強度 ×1.5，擊退有額外信用點）
- 防禦砲塔：每級一座（攻 8、血 40），不佔人口、戰後自動修復；階段 5 起襲擊改為掠奪者
- 異星研究院：異晶研究線（異晶催化、晶格建材、異晶砲管），駐點研究員也加快所有研究
- 星城穹頂：指揮艙 Lv5，需要人口 80、累計賺進 5,000 信用點

## 與 GDD 不同的地方

- 襲擊強度只隨「擊退次數」成長（GDD 是隨總襲擊次數）：原本輸一次就更難贏，模擬器裡會一路輸 21 次。
- 第一次襲擊在進入階段 4 後 8 分鐘，之後每 6–9 分鐘一次（GDD 對齊影片是 65 分鐘，本作整體節奏較快）。
- 陸戰隊員＝陸戰隊營區的駐點工人，每人佔 1 人口；武器從庫存自動配發，陸戰隊員減少時武器退回庫存。
- 陸戰隊營區升級線「訓練速度 +50%」改為「受傷休養時間 −50%」（本作沒有訓練時間）。
- 離線期間不會發生襲擊。
- 掠奪者強度從階段 5 重新起算（3 名起跳，每擊退一次 +1 名、數值 ×1.1），否則承接第 4 章的擊退次數會一進階段 5 就打不過。
- 星城穹頂成本改為岩材 3,000、金屬 1,200、信用點 3,000、異晶 300（GDD 為岩材 5,000、金屬 2,000）：倉容上限到不了 5,000。另外生活艙上限提高到 Lv20、貨櫃到 Lv25，才住得下 80 人。
- 太空港成本改為金屬 800、信用點 400（GDD 金屬 1,200）。
- 數值調整（依模擬器統計）：金屬礦井每位工人 0.2 → 0.3/秒；階段 3–4 的建築、升級節點和研究，部分金屬成本改用零件（原本零件長期滿倉、金屬長期見底）。`npm run sim` 會列出各資源的累計產量、滿倉時間和見底時間。

- 逃生艙提供 +100 儲存：GDD 初始上限 100，但緊急營地要 120 廢料，照原數值會卡關。
- 工人指派從一開始就能用；緊急營地解鎖的是「建築升級」和「升級線」。
- 金屬礦井的「點擊掉異晶碎片」和鍛造廠的「武器攻擊力」屬於階段 4 內容，MVP 先換成點擊產量 +1、工具產量 +25%。
- 隕石雨和求救訊號從階段 2 開始（隕石雨的加固要花岩材，階段 1 還沒有岩材）。
- 每人營養消耗從 0.1/秒 調高到 0.25/秒（`formulas.ts` 的 `FOOD_PER_POP`），開局營養 20 → 60。原值下糧食幾乎不會不夠。
- 新增失敗結局：斷糧 60 秒後每 30 秒有一位殖民者離開，只剩 1 人時殖民地瓦解，可回到本章開頭（每章開始自動存檢查點）或重新開始。離線期間不會有人離開。
- 休閒艙的「食物安全度計算加成」實作為：每位駐點工人讓食物安全度 +10%。
