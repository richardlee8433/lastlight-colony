# Lastlight Colony — Chapter 4 Building Sprites (Blueprint Era)

## Instructions for the image AI

You will create **6 building sprites** for a pixel-art colony sim, **one image per message, in the order listed below**.

- After each image, stop and wait for the user to say **"next"** (or give feedback) before making the next one.
- If the user gives feedback, redo the same building before moving on.
- Use the file name shown for each building (for example `colony_core.png`).

### What this set is about

Until now, the colonists built everything with their own know-how: riveted panels, bolted frames, exposed pipes, tarps. That was the limit of their technology.

In this chapter they start building from **blueprints of a far more advanced technology** and powering them with **violet energy crystals**. These buildings should feel like **a clear jump to a new era**: seamless, smooth, elegant and high-tech, clearly beyond what the colonists could have designed themselves.

They are still built and used **by the same small colony**, though, so each building keeps **a few small human touches** next to it: an old crate, a patched cable plugged into it, a handmade tool rack, a potted plant.

### Keep consistent with the earlier sets

The user may attach images from the earlier buildings. **Match them exactly in camera angle, pixel size, outline weight, lighting direction and shadow style.** Only the construction style and materials change. It must look like the same game, drawn by the same artist.

## Style Rules (apply to every image)

```
low resolution pixel art game building sprite, about 64 pixels wide, chunky pixels, bold simple shapes readable at small size,
single building centered, front-facing top-down view like Stardew Valley buildings, camera looking down from the south,
front wall faces the viewer squarely, only the roof and front face visible, no side walls, not isometric, not rotated,
light from top-left, crisp dark outline, limited color palette,
transparent background, no ground, no text, no letters, no logos, no people, no fire, no smoke,
sci-fi colony on a red desert planet with no breathable air, cozy colony sim style like Hearth and Hamlet
```

**Blueprint-era look** (for the buildings marked "full"):

```
advanced high-tech building made from alien blueprints, seamless one-piece pearl-white shell with smooth curved surfaces,
no visible rivets or bolts, thin glowing violet and teal energy lines inlaid in the surface, softly glowing violet crystal elements,
elegant tapered shapes, floating or cantilevered parts, frosted glass panels, clean and precise,
with a few small human colony touches beside it (an old crate, a patched cable, a small tool rack)
```

**Blueprint-era look, adapted** (for the buildings marked "adapted": familiar functions rebuilt with the new materials):

```
colony building rebuilt with new high-tech materials, smooth pearl-white curved shell panels with only a few visible seams,
thin glowing teal energy lines, a small violet crystal power cell, cleaner and more elegant than older colony buildings,
while still recognisably practical, with a few human colony touches beside it
```

**Colony-made look** (only for the Memorial Hall, on purpose built the old way):

```
built by the colonists by hand from salvaged escape pod hull pieces and older colony parts, riveted and patched,
lovingly maintained, warm and humble, in the same style as the earliest colony buildings
```

### Color and material guide

| Era | Main material | Accent colors | Construction |
|---|---|---|---|
| Earlier chapters (for reference only) | worn cream-white metal | orange, rust, some teal | rivets, bolts, pipes, tarps |
| **This chapter** | clean pearl white | **violet crystal glow, teal energy lines** | seamless, curved, inlaid light |

- **No oxygen on this planet:** never draw fire, flames, torches or dark smoke. Use crystal glow, energy lines, LED light, screen glow or white vapor.
- **Size:** small buildings fill about half the canvas; large buildings (command modules) fill about three quarters.
