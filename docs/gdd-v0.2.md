## 1. 一句話概念

從一艘墜毀的逃生艙開始，把一群逃離企業奴役的殖民者，帶成一座能向星系發出信號的星城。

## 2. 故事骨架

殖民者原本是「赫利昂企業」的契約勞工，被困在惡劣的採礦星球上。一次叛逃後，逃生艙墜落在一顆未登記的行星。玩家帶領倖存者求生、擴張，最後建成星城，發射信標向星系宣告獨立。

赫利昂企業在中期以「使者」身份出現，提出上繳要求，玩家可以選擇與它貿易或完全拒絕（可設計「全程不與企業交易」成就）。

| 章節 | 階段 | 主線目標 | 敘事重點 |
|---|---|---|---|
| 1 墜落 | 墜毀營地 | 建立緊急營地 | 三個倖存者的第一晚 |
| 2 扎根 | 營地 | 建成中央艙 | 發現這顆星球能住人 |
| 3 金屬與火 | 中央艙 | 打造第一批工具 | 從撿破爛到製造 |
| 4 異晶 | 前哨站 | 第一次抵禦異星生物 | 這顆星球不歡迎他們 |
| 5 企業的影子 | 殖民地 | 接待企業使者、做出選擇、通過殖民憲章 | 自由的代價 |
| 6 信標 | 星城 | 建成軌道信標 | 結局 |

## 3. 核心循環

```
按住建築手動採集（暴擊、給該建築工人 buff）
   ↓
營養囤積 → 食物安全度 ↑ → 人口成長 → 更多工人
   ↓                                  ↓
建築（提高上限）← 原料產出 ← 工人指派
   ↓                 ↓
各建築升級線     加工鏈（廢料→零件、金屬→工具/武器）
   ↓
指揮艙升級（解鎖下一階段）→ 新建築 / 新資源 / 新系統
   ↓
規模變大 → 外部威脅（自動戰鬥）+ 治理需求（稅、憲章、士氣）
```

設計原則：

- 系統分批解鎖，每階段只加一層新的管理維度
- 手動點擊整局都有價值（buff 工人），不會在自動化後變得多餘

## 6. 手動點擊

影片顯示點擊在整局都有用，這是 clicker 手感的核心。

- 所有生產建築都可按住，每 0.2 秒算一次點擊
- 點擊產量：基礎 1，可由建築升級線提高
- 暴擊：基礎 5% 機率，產出 ×5
- 工人 buff：玩家在某建築點擊時與停手後 5 秒內，該建築工人產量 +25%
- 加工建築也可點擊，點擊時加工速度提高

這個 buff 設計讓玩家在自動化之後仍有理由「巡場」，也是原作評測提到的「快速移動到各資源點」功能的由來。建議做一個建築快捷列，讓玩家一鍵跳到指定建築。

## 7. 人口與食物安全度

- 起始 3 人，每人消耗營養 0.1 / 秒
- 食物安全度 = `營養存量 ÷ (人口 × 0.1 × 120)`，上限 100%（等於存了 2 分鐘的糧食）
- 新殖民者抵達間隔：`30 秒 ÷ (0.25 + 食物安全度) ÷ (1 + 出生率加成)`
  - 安全度 0%：120 秒一人
  - 安全度 100%：24 秒一人
- 營養歸零：停止成長，士氣每秒 −1
- 人口上限由生活艙等住宅建築決定
- 閒置殖民者不產出，需手動指派

## 8. 數值公式（初版）

**原料產量**
```
每秒產量 = 工人數 × 基礎產率 × (1 + 建築升級加成 + 全域研究加成) × 士氣倍率 × 點擊 buff × 憲章倍率
```

| 建築 | 每位工人基礎產率 / 秒 |
|---|---|
| 殘骸堆 | 0.5 廢料 |
| 藻類槽 | 0.5 營養 |
| 生物採集站 | 0.8 營養（工人上限低） |
| 水耕農場 | 1.2 營養 |
| 岩層切割機 | 0.3 岩材 |
| 金屬礦井 | 0.2 金屬 |
| 異晶合成室 | 0.05 異晶 |

**加工**

| 建築 | 每位工人每秒 |
|---|---|
| 組裝工坊 | 消耗 1 廢料 → 產 0.4 零件 |
| 鍛造廠 | 消耗 1 金屬 → 產 0.3 工具或 0.3 武器（每位工人指定產品） |

原料不足時加工停擺，這會自然形成「一下缺這、一下缺那」的調度壓力。

**建築升級成本**
```
成本 = 初始成本 × 1.15^(目前等級)
Lv5 以上每級額外需要 工具 × 等級
```

**士氣（0–100，初始 60）**
```
士氣倍率 = 0.8 + 0.4 × (士氣 / 100)   → 0.8x 至 1.2x
```

| 士氣來源 | 影響 |
|---|---|
| 食物安全度 > 50% | +10 |
| 人口達上限 90% 以上 | −10 |
| 稅率每一級 | −5 |
| 休閒艙、紀念堂、總督府、天幕住宅 | 見建築表 |
| 憲章 | 見第 11 節 |

**離線收益**：50% 效率，上限 8 小時，加工建築離線照算但受原料限制。

## 9. 建築升級線

每棟建築有自己的 3–6 個升級節點，這是原作最主要的成長來源。

| 建築 | 升級節點範例 |
|---|---|
| 殘骸堆 | 點擊產量 +1 → 暴擊率 +5% → 工人上限 +1 → 暴擊倍率 ×2 → 點擊 buff 延長至 10 秒 |
| 藻類槽 | 產量 +20% → 工人上限 +1 → 產量 +30% |
| 生活艙 | 容量 +1 → 出生率 +10% → 容量 +2 |
| 休閒艙 | 士氣 +5 → 食物安全度門檻改為 90 秒 |
| 組裝工坊 | 轉換率 0.4 → 0.5 → 0.6 |
| 金屬礦井 | 產量 +20% → 點擊時有機率掉異晶碎片 |
| 鍛造廠 | 武器攻擊力 +1 → 工具產量 +25% |
| 保全站 | 保全血量 +5 → 訓練速度 +50% → 保全攻擊力 +2 |

**資料庫（全域研究）**：跨建築加成，例如所有採集產量 +10%、所有儲存 +25%、所有點擊暴擊率 +3%。

研究成本用資源支付，加上時間（30 秒到 10 分鐘，隨階段拉長）。

## 10. 戰鬥與防禦（階段 4 起）

對應影片中哥布林大軍來襲後的自動戰鬥結算。

**我方單位**

| 單位 | 攻擊力 | 血量 | 來源 |
|---|---|---|---|
| 保全 | 2 | 10 | 保全站訓練，占用 1 位人口 |
| 保全（配武器） | 5 | 10 | 每人消耗 1 武器 |
| 防禦砲塔 | 8 | 40 | 階段 5 建築 |

**敵方**

- 異星生物群：數量 `3 + 2 × 已發生襲擊次數`，每隻攻擊 2、血量 8，數值每次 ×1.1
- 掠奪者（階段 5 起）：數量較少，單體較強
- 企業突擊隊：拒絕企業三次以上才出現，強度 ×1.5，擊退有劇情獎勵

**結算**

- 回合制自動結算，最多 10 回合
- 每回合雙方以總攻擊力扣對方總血量，血量扣完的單位移除
- 勝利：獲得資源戰利品
- 失敗：敵方搶走某一資源存量的 15%，士氣 −10
- 保全不會死亡，只會「受傷」3 分鐘無法參戰（維持療癒基調）
- 戰後顯示簡短戰報

**節奏**：預警 60 秒後開打，讓玩家有時間臨時調工人去鍛造武器。

## 11. 殖民憲章（階段 5）

同時生效數量有上限（行政中心 1 條，總督府 +1）。

| 憲章 | 效果 | 代價 |
|---|---|---|
| 配給制 | 營養消耗 −20% | 士氣 −10 |
| 雙班制 | 所有產量 +15% | 士氣 −10 |
| 開放移民 | 出生率 +30% | 士氣 −5 |
| 休息日 | 士氣 +15 | 所有產量 −10% |
| 企業合約 | 信用點收入 +40% | 企業關係 +1，士氣 −5 |
| 異星優先 | 異晶產量 +25% | 金屬產量 −15% |

**稅制**：`信用點收入 / 秒 = 人口 × 0.02 × 稅率等級（0–4）`

## 14. 美術方向

全部用 Pixi Graphics 或 CSS 像素風程式化生成，不走素材管線：

- 背景：多層星空視差，地表用色塊加噪點
- 建築：幾何形體（圓頂、方艙、天線）加發光描邊，升級時加層或變色
- 工人：2–3 像素小人沿軌道線移動
- 點擊回饋：資源數字彈出，暴擊時放大加閃光，buff 期間建築外圈發光
- 戰鬥：簡單的敵我色點對撞加戰報面板
- 階段色調：墜毀營地暗紅 → 營地冷白 → 前哨站暖燈 → 殖民地起出現異晶紫光

## 16. MVP 範圍

做到階段 3 結束，約 40 分鐘內容，剛好對應影片前 42 分鐘，方便直接比對手感：

- 資源：營養、廢料、岩材、零件、金屬、工具
- 建築：階段 1–3 全部（共 16 棟）
- 點擊系統完整（暴擊、工人 buff）
- 建築升級線、資料庫研究
- 食物安全度與人口成長
- 主線第 1–3 章
- 事件 2 種（隕石雨、求救訊號）
- 離線收益、本機存檔
- 數值模擬器

戰鬥、治理、貿易、異晶留到 MVP 之後。
